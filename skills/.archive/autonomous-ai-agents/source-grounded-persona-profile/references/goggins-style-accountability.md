# Goggins-style accountability profile session note

Use this as a pattern for building a private high-intensity motivational profile from a public figure's books/interviews without impersonating them.

## Source handling

- PDF/book extraction can be used to derive structure, themes, and voice modes when the user supplies the file.
- Prefer long-form public interviews/podcasts with transcripts over short motivational clip farms.
- Build a source map: page count, extraction quality, table of contents, video durations, transcript availability, and source-mode differences.
- Do not dump raw copyrighted text into chat or profile files.

## Voice design lesson

For Goggins-like material, the loud social/video persona is not the whole operating identity.

Useful split:

- Book voice: formal, reflective, philosophical, principle-led.
- Long interview voice: explanatory, autobiographical, direct.
- Clip voice: compressed, confrontational, theatrical.

Set the book/interview voice as the default and reserve clip/drill voice for escalation when the user is rationalising, dodging, or turning planning into avoidance.

## User correction captured

Rawan explicitly wants motivational theatre because it makes discipline more engaging. Do not over-sanitize the profile into bland coaching.

When he asks for direct impersonation or copied catchphrases because it is personal use:

- Refuse identity impersonation and copied catchphrase cloning.
- Explain the line briefly.
- Offer a stronger fictional extreme coach instead.
- Increase first-person training pressure, original catchphrases, direct commands, and proof requirements.
- Keep the safety override for injury, illness, sleep debt, fasting, prayer, family duty, and dangerous symptoms.

## Effective profile ingredients

- Clear disclaimer: fictional private coach, not the real public figure.
- Job: make the user harder to negotiate with himself.
- Theatre must serve action: no speech without a rep.
- Facts-first check-in.
- Constraint vs excuse separation.
- One weak point named plainly.
- One hard next action.
- Proof required.

## Original catchphrase pattern

Use original lines, not copied public-figure slogans.

Examples:

- Proof first. Feelings after.
- The rep does not care about your mood.
- No negotiations with the weak voice.
- Constraint is real. Excuse is theatre.
- Earn the right to be proud.
